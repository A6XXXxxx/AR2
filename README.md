# AR เครื่องซักผ้า (แบบไม่ต้องใช้ marker) 🧺

เปิดกล้องแล้วเครื่องซักผ้า 3D ปรากฏขึ้นทันที ปรับความเร็วรอบ (RPM) ได้ด้วยปุ่มกด
ลากนิ้วหมุนดูรอบทิศ และใช้ปุ่ม +/− ซูมเข้า-ออกให้ขนาดพอดี สร้างด้วย A-Frame

## ไฟล์
- `index.html` — หน้าเว็บ AR (มีไฟล์เดียวก็ใช้ได้)

## อัปขึ้น GitHub + เปิด GitHub Pages
> AR ต้องเปิดผ่าน **HTTPS** กล้องถึงทำงาน — GitHub Pages ให้ HTTPS ฟรี

1. สร้าง repo ใหม่บน GitHub (ตั้งเป็น **Public**)
2. กด **"uploading an existing file"** ลาก `index.html` เข้าไป → Commit
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch **main** / **/(root)** → Save
4. รอ 1–2 นาที ได้ลิงก์ `https://<username>.github.io/<repo>/`

## วิธีใช้งาน
1. เปิดลิงก์บนมือถือใน **Safari (iPhone)** หรือ **Chrome (Android)** — อย่าเปิดในแอป Line/FB (บล็อกกล้อง)
2. แตะ **"📷 แตะเพื่อเปิดกล้อง"** แล้วกด **อนุญาต**
3. เครื่องซักผ้าจะโผล่กลางจอทันที
   - **ลากนิ้ว** = หมุนดูรอบ
   - ปุ่ม **+/−** มุมขวาบน = ซูมเข้า/ออก
   - ปุ่มด้านล่าง = ปรับความเร็ว (ปิด/ซัก/ล้าง/ปั่นหมาด/ปั่นแห้ง/อัตโนมัติ) และ +/− ปรับ ± 50 รอบ

## แก้ปัญหา
- **จอดำ/ไม่มีภาพกล้อง** → เปิดในแอปที่บล็อกกล้อง หรือยังไม่กดอนุญาต → เปิดใน Safari/Chrome แล้วอนุญาต
- **กล่องแดง error** → อ่านข้อความในกล่อง จะบอกสาเหตุ (สิทธิ์กล้อง/ไลบรารีโหลดไม่ได้)
